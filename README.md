# Бешеные ракетки — сайт клуба

Одностраничный сайт клуба любителей бадминтона в Саратове.
Чистые HTML, CSS и JavaScript: ни сборки, ни зависимостей, ни бэкенда.

Всё содержимое сайта — расписание, цены, акции, турниры, тренеры, вопросы,
картинки — редактируется в админке **Pages CMS** (https://app.pagescms.org) без программиста.
Админка сохраняет изменения прямо в этот репозиторий, GitHub Actions публикует сайт,
и примерно через минуту правка видна на сайте.

## Что где лежит

```
.pages.yml                 настройка админки: разделы и поля с русскими подписями
site/                      публикуемая папка — это и есть сайт
  index.html
  css/style.css
  js/app.js                загрузка содержимого и отрисовка блоков
  content/*.json           содержимое сайта (его правит админка)
  media/                   картинки, загруженные через админку (афиши, фото, логотипы)
  assets/                  оформление: логотип, маскот, иконки, фавикон — не для админки
  .nojekyll
.github/workflows/deploy.yml
```

Каждый файл в `site/content` — один блок сайта:

| Файл | Раздел в админке |
|---|---|
| `settings.json` | Главный экран и контакты |
| `schedule.json` | Расписание |
| `venues.json` | Площадки |
| `trainings.json` | Виды тренировок |
| `promos.json` | Акции |
| `tournaments.json` | Турниры |
| `coaches.json` | Тренеры |
| `partners.json` | Партнёры |
| `faq.json` | Вопросы и ответы |
| `socials.json` | Соцсети (внизу страницы) |

## Как подключить Pages CMS (один раз)

1. Зайдите на https://app.pagescms.org и войдите через GitHub — аккаунтом, у которого есть
   доступ к репозиторию `furiousrackets/furious-rackets-app`.
2. Pages CMS попросит установить своё GitHub-приложение — разрешите доступ к этому репозиторию.
3. Откройте репозиторий в списке: слева появятся разделы «Расписание», «Площадки», «Акции» и т. д.
4. Чтобы админ клуба мог править сайт **без своего GitHub-аккаунта**, пригласите его по почте:
   в Pages CMS откройте репозиторий → Collaborators → Invite collaborators → email. Ему придёт ссылка для входа.
   Такой участник может менять содержимое и картинки, но не настройки админки и не код.

## Как пользоваться админкой

- Слева выбираете раздел, записи в нём свёрнуты — нажмите, чтобы раскрыть.
- **Add an item** — добавить запись, значок корзины — удалить, перетаскивание — поменять порядок.
  Порядок на сайте такой же, как в админке.
- **Save** — сохранить. Через минуту изменения на сайте.
- Переключатель **«Показывать на сайте»** — спрятать запись, не удаляя её.
- **«Показывать до»** (акции, турниры) — дата в календаре. На следующий день запись сама
  исчезнет с сайта. Пусто — бессрочно.
- **Картинки**: в поле «Афиша», «Картинка», «Фото» или «Логотип» нажмите на поле и загрузите файл
  или выберите уже загруженный. Все картинки видны в разделе **Media**.
  Лучше загружать JPG/PNG/WebP до ~1 МБ: тяжёлые фото с телефона сайт покажет, но медленнее.
- Если в блоке не осталось видимых записей, блок и его пункт в меню исчезают сами.

Словарик английских кнопок: Save — сохранить, Add an item — добавить запись, Delete — удалить,
Media — картинки, Cancel — отмена.

### Правила заполнения

**Расписание и площадки связаны** по короткому названию: в поле «Площадка» расписания пишите
название ровно как в поле «Короткое название» раздела «Площадки» (регистр не важен).
Сайт подставит полное название и добавит в карточку площадки дни тренировок.
Так же работает поле «Где» у турниров.

- «Уровни» — выбираются из списка. Ничего не выбрано — на сайте будет «все уровни».
- «Тип» — рабочая или игровая (игровые подсвечиваются салатовым).
- «Цена» — только число, знак ₽ сайт добавит сам.
- «Ссылка на карту» можно не заполнять: сайт построит ссылку на Яндекс Карты по адресу.

**Ссылки внутри текста.** В описаниях тренировок, акциях, турнирах и ответах можно поставить
`{телефон}`, `{тренер}` или `{группа}`. Сайт заменит их на кликабельные ссылки из раздела
«Главный экран и контакты», так что при смене номера тексты править не придётся.

**Ссылки в полях** принимаются только вида `https://`, `http://`, `tel:`, `mailto:` и пути внутри
сайта. Остальное сайт игнорирует — это защита от чужих скриптов.

## Как посмотреть локально

Содержимое загружается из `site/content/*.json`, а браузер не даёт читать файлы при открытии
страницы двойным кликом. Поэтому нужен локальный сервер:

```bash
cd site && python3 -m http.server 8000
```

Дальше откройте http://localhost:8000 — остановить сервер можно по Ctrl+C.

Не забывайте делать `git pull` перед правками кода: админка коммитит в `main`.

## Как включить GitHub Pages

1. Settings → Pages → Source: выберите **GitHub Actions**.
2. Дальше всё само: при каждом push в `main` (в том числе при сохранении в Pages CMS)
   workflow `.github/workflows/deploy.yml` публикует папку `site`. Его же можно запустить
   руками — вкладка Actions → Deploy to GitHub Pages → Run workflow.
3. Сайт появится по адресу `https://<логин>.github.io/<название-репозитория>/`.

## Для разработчика: как добавить поле или блок

1. Добавьте поле в нужный раздел `.pages.yml` (`name` — ключ в JSON, `label` — подпись для админа).
   Типы полей: https://pagescms.org/docs/configuration/content/fields/
2. Прочитайте его в `site/js/app.js` через `cell(row, '<name>')` (для картинок — `mediaUrl(...)`).
3. Списки хранятся как `{ "items": [...] }` — так в админке работают свёрнутые записи с подписями.
   Не меняйте `name` существующих полей: старые данные перестанут находиться.
